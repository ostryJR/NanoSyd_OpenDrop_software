Templates

Drag one onto the electrode the droplet is on. It starts in the frame on screen. R turns it while you drag, Esc cancels.

Yours

    None yet. Press + New, draw the operation and save it, or press ✎ on a built-in one to start from a copy.

    Built in

      New template

      Draw the operation on the array with any of the tools, starting in frame 1. Frame times you set are kept too. The template is dropped by the leftmost electrode of its first frame (the top one if there are several).

      Drag: path (F freehand, S straight, P paint) · Esc: cancel · ⌘Z / ⇧⌘Z: undo/redo · Click: toggle · Shift+click: next frame + on · ←→ or wheel: frame · Space: play/stop (wheel: speed)
