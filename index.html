    Built in

    This browser can't reach USB devices. Open the page in Chrome or Edge on a computer.

    Not connected

    In the list the browser shows, look for the Feather M0 device.

    Live

    Switch live on and off with the red live box on the board, under simulate: the device then shows the frame on screen.

    Feedback

    High voltage

    Set them for the project in Properties, under the frame time; they go to the device when it connects and whenever they change, until it is switched off. Save to device keeps them on it for good. Needs the custom firmware (OpenDropVCustom).

    Temperatures

    NowTarget

    Sequence on the device

    To run on its own, with each frame's time, the device needs firmware that takes a whole sequence (protocol 1, see docs/device-protocol.md). Today's firmware only follows live frames: use live and play instead.

    Traffic log

    → sent, ← received, × no answer. Each entry: what it says (as the custom firmware reads it), then the bytes in hex. Nothing is logged while this is off.

    New template

    Draw the operation on the array with any of the tools, starting in frame 1. The template is dropped by the leftmost electrode of its first frame (the top one if there are several).
